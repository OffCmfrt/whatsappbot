Testing

How to test the widget

  1. Click the black chat button in the bottom-right corner
  2. Try the quick actions: Track Order, Return Policy, Talk to Support
  3. For tracking, try entering an order number like #1234 or an AWB
  4. Click "Talk to Support" to test the ticket creation flow
  5. After creating a ticket, click "Continue on WhatsApp" to test the deep link
  6. Refresh the page -- your chat history should persist in sessionStorage

Welcome to the OFFCOMFRT Store

This is a test page simulating the Shopify storefront. The support widget should appear as a floating button in the bottom-right corner. Click it to open the AI-powered support chat.

Embed Code for Shopify

Add this to your Shopify theme's theme.liquid file, just before the closing </body> tag:


<script src="https://your-bot-server.onrender.com/widget/loader.js" defer></script>

With Customer Data (Shopify Liquid)

To pre-fill customer info, add this before the loader script:


<script> window.__offcomfrt_widget = { apiUrl: 'https://your-bot-server.onrender.com', customerName: '{{ customer.first_name }}', customerEmail: '{{ customer.email }}', customerPhone: '{{ customer.phone }}' }; </script>
